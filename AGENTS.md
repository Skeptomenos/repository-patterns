# Repository context

Ownership-ID: Personal

- This repository is a recommendation library, not a policy or compliance rulebook.
- Read `README.md`, then `index.md`, before choosing a deeper document.
- Use `docs/catalog.md` to select a pattern by need. Read one pattern and one case study before recommending adoption.
- Keep these labels distinct: `Observed`, `Inferred`, `Recommended`, `Trade-off`, and `Example`.
- Every pattern must state when it helps, when it does not, what it costs, and where the example came from.
- Prefer the smallest useful adoption. Do not copy a repository's structure just because the example is impressive.
- Link durable documentation from `README.md`, `index.md`, or the relevant catalog page in the same change.
