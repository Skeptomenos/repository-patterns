# Patterns

Each pattern page follows the same shape:

1. the problem it addresses;
2. when it is useful;
3. a small conceptual shape;
4. the Pi example;
5. benefits and trade-offs;
6. signals that it may be a poor fit;
7. questions for adoption.

The pages are recommendations. They are intentionally not written as mandatory repository rules.
